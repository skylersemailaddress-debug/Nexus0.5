# Confidence + Risk System

## Confidence
0-100 score derived from:
- completeness
- validation
- consistency
- execution success

## Risk
Categories:
- missing data
- unverified output
- time sensitivity
- system uncertainty

## Example
```
Confidence: 82%
Risk: Medium
- Missing environment validation
- Not tested under load
```

## Rule
Every execution or major output should include confidence and risk.
