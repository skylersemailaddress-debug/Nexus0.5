# Nexus0.5 UI Canon

## Core Rule
Chat is the only persistent anchor.

## Canonical Surface Model
- One active context surface at a time
- No static dashboard panels
- Context surfaces replace or transform rather than accumulate
- Watch surfaces are temporary and inline

## Required Modes
- Onboarding
- Briefing
- Resume
- Prep
- Quiet

## Watch Surface Types
- code
- decision
- system
- preview
- data

## Confidence Rule
Every major output should support confidence and risk display.
