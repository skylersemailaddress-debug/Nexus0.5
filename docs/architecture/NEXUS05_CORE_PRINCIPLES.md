# Nexus0.5 Core Principles

## Interaction Model
- Chat is the only persistent interface element
- All other UI is dynamically generated from context
- No static panels or dashboards

## Surface Model
- One active context surface at a time
- Blocks render based on system state
- Blocks replace/transform, not accumulate

## Trust Model
- Show work (watch surfaces)
- Show confidence
- Show risk

## System Relationship
- Nexus0.5 = runtime UI + product surface
- NexusV3 = builder/orchestrator

These must remain separate systems.
